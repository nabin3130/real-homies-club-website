# Real Homies Club
<img width="1426" height="761" alt="realhomiesclub_web" src="https://github.com/user-attachments/assets/1759ecad-a713-4319-9d69-b76a045ce11e" />

A branded community landing page designed for Real Homies Club, bringing together social channels, community updates, and collaboration opportunities in one destination.

The website provides a central hub where community members can discover content, access social platforms, and connect with the project's identity through a clean and engaging user experience.

## Highlights

Community Branding → Social Hub → Content Discovery → Collaboration

## Features

- Branded landing page for a Web3 community
- Centralized access to TikTok, Instagram, YouTube, and X
- Responsive design for desktop and mobile
- Interactive UI with animations and custom branding
- Collaboration and contact section
- Google Tag Manager integration for visitor analytics

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Google Tag Manager
- Vercel

## Live Demo

https://real-homies-club.vercel.app/

## Why I built this

Growing communities often rely on multiple social platforms, making it difficult for new members to discover content and stay connected.

I built this landing page to create a single branded destination where visitors can easily access community channels, understand the project's identity, and explore collaboration opportunities through a modern, responsive, and engaging interface.
