# Real Homies Club Website

A deploy-ready one-page website built with Next.js, TypeScript, and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a new GitHub repository.
2. Upload this project or push it with Git.
3. In Vercel, choose **Add New Project** and import the repository.
4. Keep the default Next.js settings and click **Deploy**.

## Before publishing

Update these placeholders in `app/page.tsx`:

- `hello@realhomies.club`
- YouTube, Instagram, and X links
- Work-card links
- About copy

You can also replace the `RH` text mark with an image logo later.
